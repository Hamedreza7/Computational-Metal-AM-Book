# Case 2 — Thermo-Mechanical Stress

**Book link:** Chapter 6, Case 2

## Purpose
Use the Case 1 final temperature vector to compute the spatially averaged temperature, fully constrained elastic stress, and stress-free-temperature residual-stress surrogate.

## Run
```bash
python main.py
```

## Expected output
- `stress_summary.csv`

## Scope and limitations
This is a compact educational reference implementation. It is intended to make the mathematical workflow executable and transparent; it is not a validated production solver for safety-critical engineering use.
