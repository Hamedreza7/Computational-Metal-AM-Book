# Case 1 — 6-Node Moving-Source FDM

**Book link:** Chapter 6, Case 1

## Purpose
Reproduce the four explicit time steps of the six-node LPBF heat-conduction example.

## Run
```bash
python main.py
```

## Expected output
- `temperatures.csv`
- `temperature_history.png`

## Scope and limitations
This is a compact educational reference implementation. It is intended to make the mathematical workflow executable and transparent; it is not a validated production solver for safety-critical engineering use.
