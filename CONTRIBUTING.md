# Contributing

The primary purpose of this repository is to provide stable educational companion code for the book.

For the book-associated `v1.0.0-book` release, changes should preserve:

1. correspondence with the equations and case studies in the published manuscript;
2. readable, minimal implementations;
3. deterministic examples where practical;
4. explicit units and parameter definitions;
5. clear separation from proprietary or commercial software.

Bug reports and documentation corrections are welcome through GitHub Issues after the repository becomes public.
