# Binder Infiltration — Lucas–Washburn

**Book link:** Chapter 3, Section 3.4

## Purpose
Compute capillary pressure and idealized binder penetration distance, including sensitivity to contact angle. The example implements the chapter equations directly.

## Run
```bash
python main.py
```

## Expected output
- `penetration_vs_time.png`
- `penetration.csv`

## Scope and limitations
This is a compact educational reference implementation. It is intended to make the mathematical workflow executable and transparent; it is not a validated production solver for safety-critical engineering use.
