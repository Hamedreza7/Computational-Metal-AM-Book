# ECAM Faradaic Growth

**Book link:** Chapter 3, Sections 3.12.3–3.12.5

## Purpose
Compute a diffusion-limited current density and convert an imposed deposition current density into Faradaic normal growth velocity.

## Run
```bash
python main.py
```

## Expected output
- `growth_vs_current.png`
- `growth_table.csv`

## Scope and limitations
This is a compact educational reference implementation. It is intended to make the mathematical workflow executable and transparent; it is not a validated production solver for safety-critical engineering use.
