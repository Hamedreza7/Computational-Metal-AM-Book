# Moving Gaussian Heat Source

**Book link:** Chapter 2, Section 2.1.3; also supports Chapter 6 Case 1

## Purpose
Evaluate and visualize the moving one-dimensional Gaussian volumetric heat source using the same representative source parameters as the worked 6-node thermal case.

## Run
```bash
python main.py
```

## Expected output
- `gaussian_heat_source.png`
- `source_profiles.csv`

## Scope and limitations
This is a compact educational reference implementation. It is intended to make the mathematical workflow executable and transparent; it is not a validated production solver for safety-critical engineering use.
